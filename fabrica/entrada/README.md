# Entrada de propuestas

Aquí llega lo que genera ChatGPT, antes de aprobarse. Una carpeta por pieza y fecha:

```
entrada/2026-11-21_rol_vigia/
  rol_vigia__v1.png      ← imagen tal como salió
  rol_vigia__v1.txt      ← prompt exacto que se usó
  rol_vigia__v2.png
  rol_vigia__v2.txt
  REVISION.md            ← revisión técnica (Claude) y decisión (Jonathan) por versión
```

Nada de esta carpeta lo usa el juego. Lo aprobado pasa a `objetos/` y al canon con su hash; lo rechazado se queda aquí con su motivo.
