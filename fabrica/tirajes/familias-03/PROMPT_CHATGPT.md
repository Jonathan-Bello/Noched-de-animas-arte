# Prompt para ChatGPT · familias-03 (imágenes)

Un bloque por carta. Abre un chat nuevo de ChatGPT por carta, adjunta las imágenes de la lista (descárgalas de los enlaces) y pega el bloque. ChatGPT inventa dos escenas propias y entrega **dos ilustraciones**, C y D. Mándame las imágenes en el hilo con el nombre `<id>-c.png` y `<id>-d.png` y las publico junto a las dos de Claude.

Las escenas A y B las escribió Claude y también las dibuja ChatGPT, con `PROMPT_CHATGPT_AB.md`. Los bloques de aquí le dicen a ChatGPT cuáles son, para que no las repita.
